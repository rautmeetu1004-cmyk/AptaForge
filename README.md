# Aptaforge — a sequence surrogate for ssDNA aptamer folding energy

Aptaforge learns to predict the folding free energy of single-stranded DNA
aptamers directly from sequence, so that large candidate pools can be triaged in
milliseconds instead of running an exact thermodynamic solver on every sequence.
This repository contains the data, models, and figure code behind the manuscript.

The central result is a **leak-free** benchmark: because folding energy is a
deterministic function of sequence, the corpus is deduplicated to unique
sequences and every fold is split **by sequence**, so no sequence appears in both
train and test. On that protocol a gradient-boosted k-mer model recovers most of
the folding signal and predicts folding energy **~200× faster** than the exact
solver.

## Results (leak-free, 5-fold, split by sequence; n = 1,426 unique sequences)

| Model                        | R²    | Spearman | MAE (kcal/mol) |
|------------------------------|:-----:|:--------:|:--------------:|
| Length only (Ridge)          | 0.333 | 0.631    | 2.37           |
| Length + GC (Ridge)          | 0.399 | 0.700    | 2.21           |
| **k-mer surrogate (HistGBM)**| **0.611** | **0.798** | **1.80**   |
| 1D-CNN surrogate             | 0.538 | 0.770    | 1.94           |

The k-mer surrogate beats the length+GC baseline with high significance
(Wilcoxon *p* ≈ 8×10⁻¹⁸) and is seed-stable (R² std = 0.00). A mean-predictor
tripwire gives R² ≈ 0, confirming the protocol carries no target leakage.
All numbers are consolidated in [`results/FINAL_NUMBERS.json`](results/FINAL_NUMBERS.json).

## The two models

Both are defined and benchmarked on the identical folds:

- **k-mer surrogate** — `code/models/01_benchmark_histgbm.py`. Normalised 3- and
  4-mer frequencies plus length and GC, fed to a `HistGradientBoostingRegressor`.
  Deterministic and CPU-only. This script also creates the shared fold indices
  and the Ridge length / length+GC baselines.
- **1D-CNN surrogate** — `code/models/02_benchmark_cnn.py`. A small convolutional
  network over the tokenised sequence with mean/max pooling and length+GC
  auxiliaries, trained with nested early stopping on the *same* folds. Requires
  PyTorch.

## Repository layout

```
data/        input CSVs + data dictionary (see data/README.md)
results/     cached model outputs (OOF predictions, metric JSON) the figures read
figures/     final publication figures (PNG + 300-dpi TIFF)
code/
  nupack_backend.py      minimal NUPACK 4 wrapper for label generation only
  models/                the two surrogates + baselines
  analysis/              per-figure analyses that also emit their figure
  figures/               pure plotting scripts that read cached artifacts
```

## Reproducing everything

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # NUPACK is NOT needed (see note)
```

Run from the repository root, in order. Step 0 is optional and the only step that
needs NUPACK; the labels it produces are already in `data/folding_labels.csv`.

```bash
# 0. (optional) regenerate folding labels — requires NUPACK 4 installed
python code/models/00_generate_folding_labels.py

# 1. models: baselines + k-mer surrogate, then CNN (identical folds)
python code/models/01_benchmark_histgbm.py
python code/models/02_benchmark_cnn.py

# 2. per-figure analyses (each writes its metric JSON and its figure)
python code/analysis/01_kmer_analysis.py
python code/analysis/02_multiproperty.py          # Figure 09
python code/analysis/03_per_target_control.py     # Figure 10
python code/analysis/04_sequence_features.py      # Figures 05, 06 (+ sequence_features.csv)
python code/analysis/05_case_study_prescreen.py   # Figure 11
python code/analysis/06_cnn_evaluation.py         # Figure 08
python code/analysis/07_primer_analysis_nupack.py # optional, NUPACK; cached JSON shipped
python code/analysis/08_consolidate_results.py    # Figure 07 + FINAL_NUMBERS.json

# 3. remaining figures (pure plotting from cached artifacts)
python code/figures/fig00_graphical_abstract.py   # Figure 00  (needs FINAL_NUMBERS.json)
python code/figures/fig01_dataset_composition.py  # Figure 01  (needs sequence_features.csv)
python code/figures/fig02_dataset_statistics.py   # Figure 02
python code/figures/fig03_primer_analysis.py      # Figure 03  (needs step-07 JSON)
python code/figures/fig04_folding_landscape.py    # Figure 04
```

## Folding labels and NUPACK

Folding features were computed with **NUPACK 4** (`material='dna'`, 37 °C). NUPACK
is a separate package with its own terms and is not redistributed here. Only the
numeric labels it produced are shipped (`data/folding_labels.csv`), so every model
and figure in this repository reproduces without it. To regenerate labels from
scratch, install NUPACK from https://www.nupack.org and run step 0. Please cite
NUPACK if you do.
