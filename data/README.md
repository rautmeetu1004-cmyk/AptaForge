# Data

All files are DNA sequences (A/T/G/C). RNA inputs are transcribed to DNA (U→T)
before folding. Files are UTF-8 CSV with a header row.

## `aptamer_corpus.csv` — 1,625 sequences
The assembled aptamer sequence corpus, before folding and deduplication.

| column            | description                                            |
|-------------------|--------------------------------------------------------|
| `sequence`        | nucleotide sequence (DNA alphabet)                     |
| `target`          | binding target name as reported by the source database |
| `target_category` | coarse target class (e.g. Protein, Small molecule)     |
| `source`          | originating public database                            |

## `folding_labels.csv` — 1,578 rows
Per-sequence folding features computed with **NUPACK 4** (`material='dna'`, 37 °C).
Sequences with non-canonical bases or solver errors are dropped. This is the only
file that depends on NUPACK; it is provided so the rest of the pipeline reproduces
without installing it.

| column               | description                                       |
|----------------------|---------------------------------------------------|
| `sequence`, `target` | as above                                          |
| `mfe_kcal`           | minimum free energy of folding (kcal/mol)         |
| `structural_entropy` | length-normalised base-pair-probability entropy   |
| `ensemble_defect`    | normalised ensemble defect                        |
| `log_pfunc`          | log partition function                            |
| `L`                  | sequence length (nt)                              |
| `gc`                 | GC fraction                                        |

## `folding_dedup.csv` — 1,426 unique sequences
`folding_labels.csv` deduplicated to unique sequences (MFE depends only on the
sequence). This is the modelling corpus; all benchmarks split folds **by sequence**
over these rows so no sequence appears in both train and test.

| column     | description                                     |
|------------|-------------------------------------------------|
| `sequence`, `target`, `mfe_kcal`, `L`, `gc` | as above |

Generated by `code/models/01_benchmark_histgbm.py`.

## `sequence_features.csv` — 1,426 rows
Interpretable sequence descriptors (length, GC, homopolymer runs, k-mer summaries,
etc.) aligned to `folding_dedup.csv`. Generated by
`code/analysis/04_sequence_features.py`.

## Provenance
Binding-affinity annotations from the source databases are **not** included; the
released corpus is defined purely by the DNA-alphabet and length (15–100 nt)
filters, and its labels are the NUPACK folding features above.
